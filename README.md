# 市政 debug 松 — 找回消失的垃圾桶

## 「桶桶沒問題」數據驅動之行人垃圾桶動態調度與佈建計畫

本專案旨在透過 MVP（最小可行性方案）模式，以客觀數據作為垃圾桶佈建與調度之依據。結合物聯網感測技術與六角形網格空間分析（以 Uber 開源之 [H3 網格系統](https://h3geo.org/) 為基礎），採分階段推動台北市行人垃圾桶的實體優化與清運排程自動化。

## 一、預期計畫效益

1. **市容與觀光**：有效控管行人專用垃圾桶（下稱垃圾桶）滿溢狀況，維持商圈與街道整潔，提升整體公共空間品質與觀光客體驗。
2. **環境衛生**：降低廢棄物溢出，實質減少病媒蚊與鼠害孳生風險。
3. **淨零減碳**：透過感測器資訊即時掌握各桶滿溢程度，當該區有滿溢狀況即跳出告警，若達三處滿溢則進一步建議指派機動小組出勤清運。減少車隊折返所致無效行駛里程，具體降低車輛油耗與碳排放。
4. **減輕公務員負擔**：將基層清潔隊員從無效巡視中釋放，由系統提供明確的出勤任務；同時降低 1999 話務中心與承辦人員處理滿桶陳情之行政負擔。

## 三、核心資料來源

### 1. 垃圾桶佈建分析圖資（六角形網格分析）

匯集臺北捷運各站分時進出量、公車與 uBike 站點位置、區域特性（如商圈邊界），以及 1999 市民陳情熱點。系統將全區劃分為「六角形網格（均等中心距離）」，透過疊圖加權，將隱性的設桶需求具體化，作為佈建規劃之決策支援。

### 2. 垃圾桶監控與回饋數據（動態資料）

- **感測器數據**：太陽能滿桶感測器即時回傳的滿溢高度與累積速率。
- **市民 QR Code 通報**：民眾掃碼回報的現場真實狀況（如桶外違規棄置），作為系統演算法校正的重要補充因子。

## 四、經費評估與招商策略

為確保系統開發與硬體建置之專業度，計畫經費與招商作業分為「總體計畫勞務採購」與「硬體設備採購與企業合作」雙軌並行。本計畫（以第一、二階段試辦為估算基礎）預估動支公務預算約**新台幣 600 萬元**，餘由公私協力機制補足。

| 項目 | 預估經費 | 經費來源 | 招商方式 |
| --- | ---: | --- | --- |
| 勞務採購：平台建置與專案管理 | 約 4,500,000 元 | 市府公務預算 | 限制性招標（準用最有利標） |
| 財物採購：外掛式太陽能滿桶感測器 | 約 1,500,000 元 | 市府公務預算 | 環保局編列設備採購經費發包 |
| 公私協力（PPP）：智慧垃圾桶建置 | 約 3,000,000 元 | 市府零出資 | 企業 ESG 贊助 |

### 1. 勞務採購：「桶桶沒問題」平台建置與專案管理

- **預估經費**：約 4,500,000 元（市府公務預算）
- **採購說明**：包含六角形網格分析模型開發、AI 動態清運演算法導入、前端視覺化決策儀表板、API 介接，及專案執行與數據分析報告。
- **招商方式**：採限制性招標（準用最有利標），評選具備系統整合與資料分析實績之專業團隊。

### 2. 財物採購：外掛式太陽能滿桶感測器

- **預估經費**：約 1,500,000 元（市府公務預算）
- **採購說明**：包含大安與中山區試辦點位（預估 150 組）之感測器硬體購置、施工安裝及首年通訊費。
- **招商方式**：由環保局編列設備採購經費辦理發包。

### 3. 公私協力（PPP）：智慧垃圾桶建置（特定熱區升級）

- **預估經費**：約 3,000,000 元（市府零出資）
- **設置說明**：針對第二階段判定為「極高壓熱點」之商圈（預估 20–30 組），導入具備物理壓縮與太陽能供電之完整智慧垃圾桶。
- **招商方式**：企業 ESG 贊助。由產發局媒合鄰近企業運用 ESG 預算贊助建置，市府回饋市容綠美化認證或專屬桶身公益廣告空間。

## 五、階段性推動與推廣宣傳計畫

採「**特定試辦 → 數據回饋 → 全市佈建**」三階段嚴謹推動。

此分段辦理之核心考量在於：透過小規模試辦，市府能以極低的初期預算，先行驗證系統告警機制與基層清潔分隊派工流程的實務契合度；同時，藉由真實運作收集的感測器與市民回報數據，滾動式校正六角形網格佈建分析模型。待標準作業流程成熟、且順利引入民間企業資源後，再行全市擴張，確保每一筆公帑皆能精準投入於具備實質需求的熱點，將政策推行風險降至最低。

### 第一階段：特定熱點試辦與系統上線（第 1–3 個月）

**實作內容**

首先針對試辦區內既有垃圾桶進行盤點造冊，並明確區分各清潔分隊之管轄權責邊界。目前依據「市長，你給我聽好了」市民回饋分析，選定（如大安區、中山區）作為試辦場域，並於造冊之垃圾桶裝設滿桶感測器。

啟動「桶桶沒問題」平台，由系統監控各桶滿溢程度：

- 單點滿溢 → 跳出告警
- 該區累積 3 處滿溢 → 系統建議指派該管轄區之機動小組出勤清運

平台亦同步啟用「六角形網格佈建分析」功能，透過疊加捷運人流、大眾運輸站點、區域特性與市民陳情等大數據圖資，將試辦區內的隱性設桶需求具體視覺化，為下一階段的實體增撤與硬體升級提供客觀的決策支援。

**推廣宣傳**

於試辦區垃圾桶張貼 QR Code，配合市府官方 LINE 帳號推播，宣導民眾遇到滿桶時即時掃碼回報，建立基礎數據採集網絡。

### 第二階段：數據回饋分析與智慧垃圾桶導入（第 4–9 個月，為期半年）

**實作內容**

依據前三個月之感測器與民眾通報數據，進一步於試辦區域調整垃圾桶之實體配置。依據六角形網格分析結果，將設備形式分流為「一般垃圾桶＋感測器」或「智慧垃圾桶」。

**推廣宣傳（招商端）**

針對判定需設置智慧垃圾桶之熱區，舉辦企業合作說明會，落實前述之企業贊助與公私協力機制。本階段將持續掌握設備使用情形，產出分析報告以供下階段決策參考。

### 第三階段：全市佈建與常態化營運（第 10 個月起）

**實作內容**

將已驗證成熟的佈建分析模型與動態調度機制擴展至全台北市。依據各行政區網格數據特性，精準辦理全市垃圾桶之增設與裁撤。

**推廣宣傳**

發布專案成效報告，公開車隊減碳量、通報案件下降率及企業參與家數等客觀數據，展現市府數據治理之具體成效。

## 六、常態營運與長期追蹤機制

全市佈建完成並非計畫的終點，而是城市數據長期治理的起點。為確保「桶桶沒問題」平台能持續貼合台北市的都市發展脈動，將建立以下四大長期追蹤機制：

### 1. 佈建模型滾動式校正

都市空間是動態的（如新捷運線通車、新商圈崛起）。系統將設定「**每半年**」為一個檢核週期，自動匯入最新的交通局與捷運人流大數據，重新跑一次六角形網格疊圖分析。若發現特定區域需求指標大幅上升或下降，將主動產出「清潔箱遷移與增撤建議報告」，讓硬體配置永遠跟上真實需求。

### 2. 硬體妥善率與預測性維護

針對佈建於全市的滿桶感測器與智慧清潔箱，平台後台將持續監控其「設備連線狀態」與「電池健康度」。在設備完全沒電或故障前，系統會提前發出維護工單給相關單位，確保資料採集網絡的妥善率維持在 **95% 以上**，避免因感測器失效導致滿溢漏報。

### 3. 企業 ESG 績效與碳排追蹤

針對參與公私協力（PPP）贊助智慧清潔箱的企業，系統每年將結算該區域因「精準派工」省下的垃圾車無效行駛里程，並換算為具體的減碳量（CO2e）與市容改善指標。產出之量化報告不僅可納入市府的 SDGs 自願檢視報告（VLR），更能作為贊助企業撰寫年度 ESG 永續報告書的實質佐證，維持民間企業持續參與的誘因。

### 4. 市民行為與違規熱點洞察

持續追蹤 1999 陳情趨勢與 QR Code 掃碼通報內容。若系統數據顯示某點位經常發生「感測器未滿桶，但周邊卻被通報髒亂」，即可判定該處極可能是「家戶垃圾違規棄置」的黑數熱區。此洞察數據將定期同步給環保局稽查大隊，作為架設移動式監視器（科技執法）的精準打擊座標。
